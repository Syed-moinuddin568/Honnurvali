# Dargah Honnur Website

This is a modern, responsive landing page for Dargah Honnur optimized for mobile, tablet, desktop, and large screens.

## Project structure

- `index.html` — Refactored semantic markup with accessible navigation and premium hero layout.
- `assets/styles.css` — Modern responsive styling, glassmorphism, navigation, hero, section cards, and footer.
- `assets/script.js` — Mobile menu handling, smooth scrolling, toast feedback, scroll reveal, and testimonial carousel.

## Features

- Sticky desktop header
- Animated hamburger side drawer for mobile
- Responsive hero section with gradient overlay and CTA buttons
- Accessible keyboard navigation and ARIA labels
- Smooth scroll and fade-on-scroll animations
- Gallery, events, testimonials, and contact sections
- Responsive form and modern footer

## Usage

Open `index.html` in a browser to preview the site.

## Notes

- Images are loaded from Unsplash as remote placeholders.
- Form submission is handled with a client-side toast notification.
- The site is built without a framework for easy maintenance and fast loading.
